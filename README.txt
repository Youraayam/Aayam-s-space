AAYAM'S SPACE — WEBSITE FILES

Files:
- index.html  Main website structure and sample content
- style.css   Responsive styling and visual design
- script.js   Search, topic filters, article popups, mobile menu and theme toggle

PREVIEW LOCALLY:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.
3. Internet is needed for the Google Fonts import; the site otherwise works locally.

PUBLISH WITH GITHUB PAGES:
1. Create a GitHub repository (for example: aayams-space).
2. Upload index.html, style.css and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. GitHub will provide the public website address after deployment.

CUSTOMISE:
- Replace the sample article text in script.js (the articles object).
- Replace the sample cards in index.html as you publish real posts.
- Change the contact email and social links in index.html if needed.
- Add your own images to an assets folder and reference them from index.html or style.css.

The sample posts are starter content, not published research claims. The contact form/newsletter is intentionally omitted because this static site has no backend.
